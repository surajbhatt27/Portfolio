# Suraj Bhatt - Developer Portfolio

Personal portfolio website with a ⌘K command palette for keyboard-first navigation.

## Features

- ⌘K command palette to navigate between pages
- Fully responsive design (mobile + desktop)
- Terminal-inspired aesthetic
- Built with React + TypeScript

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS
- CMDK (command palette)
- Vite

## Run Locally

```bash
npm install
npm run dev
